# CampusCare

## Sistem Pelaporan Fasilitas Kampus Berbasis Web

CampusCare adalah platform berbasis web yang dirancang untuk membantu
mahasiswa melaporkan fasilitas kampus yang mengalami kerusakan serta
memantau proses penanganan laporan tersebut.

## 🎯 Tujuan

Menyediakan sistem pelaporan fasilitas kampus yang terpusat, terstruktur,
dan mudah dipantau oleh mahasiswa maupun admin atau petugas fasilitas kampus.

## 👥 Target Pengguna

- Mahasiswa
- Admin / Petugas Fasilitas Kampus

## ❗ Permasalahan

Mahasiswa sering mengalami kesulitan ketika ingin melaporkan fasilitas
kampus yang rusak secara terstruktur dan mengetahui perkembangan laporan
setelah laporan dibuat.

Contoh fasilitas yang dapat dilaporkan:

- AC tidak berfungsi
- Proyektor rusak
- Lampu mati
- Kursi atau meja rusak
- Toilet bermasalah
- Wi-Fi bermasalah
- Fasilitas kampus lainnya

## 💡 Solusi

CampusCare menyediakan website terpusat untuk membuat laporan kerusakan
fasilitas kampus dengan informasi berupa kategori, lokasi, deskripsi,
dan foto.

Admin atau petugas dapat menerima, memverifikasi, mengelola, dan memperbarui
status laporan hingga masalah tersebut selesai ditangani.

## ⚙️ Fitur Utama

### Mahasiswa

- Register & Login
- Membuat laporan
- Memilih kategori kerusakan
- Memilih lokasi fasilitas
- Upload foto
- Melihat laporan sendiri
- Memantau status laporan

### Admin / Petugas

- Login
- Melihat seluruh laporan
- Melihat detail laporan
- Memverifikasi laporan
- Mengubah status laporan
- Mengelola kategori
- Mengelola lokasi
- Melihat statistik laporan
